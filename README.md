# 🔐 Cybersecurity & Ethical Hacking – Week 3

## 📌 Week 3 Practical Lab

Welcome to my **Week 3 Cybersecurity & Ethical Hacking** practical lab repository.

This week focused on **password security, cryptographic hashes, file protection, John the Ripper, and CTF-style security challenges** in a controlled learning environment.

The objective was to understand how password-protected files and password hashes can be analyzed during authorized security testing, and why strong password practices are essential for protecting sensitive information.

---

## 🎯 Objectives

The main objectives of this week's practical work were:

- Understand password-protected files and cryptographic hashes
- Learn the fundamentals of password hash analysis
- Explore password-cracking concepts in an authorized lab
- Work with **John the Ripper (JtR)**
- Perform a controlled dictionary-based security test
- Analyze protected files in a CTF-style environment
- Identify security weaknesses caused by weak passwords
- Document the methodology and observations

## 🔎 Practical Workflow

### 1. Hash Extraction

The first stage involved understanding how password-protected files can contain information suitable for authorized password-security testing.

Cryptographic hash data was extracted from the provided lab files for further analysis.

---

### 2. Hash Analysis

The extracted hash data was analyzed to understand:

- Hash formats
- Password verification
- Hash-based authentication
- The relationship between passwords and hashes

---

### 3. John the Ripper

**John the Ripper** was used in the controlled lab environment to demonstrate how password security can be tested against dictionary-based attacks.

The exercise helped me understand why weak and commonly used passwords can create security risks.

---

### 4. CTF Challenge

The practical exercise included a CTF-style challenge where the objective was to analyze protected files and identify the required information.

The challenge helped improve my:

- Problem-solving skills
- Linux skills
- Security analysis
- Attention to detail
- Understanding of password security

---

## 💡 Key Learnings

During this week, I learned that:

- Strong passwords are an important part of information security.
- Weak or commonly used passwords can significantly reduce the security of protected data.
- Cryptographic hashing plays an important role in password protection.
- Security tools such as John the Ripper can be useful for **authorized security assessments**.
- Practical CTF challenges help develop real-world security analysis and problem-solving skills.
- Ethical hacking should always be performed with proper authorization and within a controlled environment.
